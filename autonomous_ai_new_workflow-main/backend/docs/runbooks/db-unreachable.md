# Database Unreachable

## Symptom
Connections time out or fail to establish with the target database.

## Diagnosis
1. Check the semantic connections dashboard.
2. Verify if the database is down or if it's a network issue.

## Common causes
- Firewall rules blocking access
- Target database server is down

## Mitigation
1. Verify the firewall rules.
2. Check the database server status.

## Escalation
Page the network team or database administrator.
